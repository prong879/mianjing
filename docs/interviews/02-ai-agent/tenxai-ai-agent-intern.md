- 假设 Agent 任务执行到一半卡住，用户等了很久，你怎么优化体验？
- 假设客户要求 Agent 支持私有化部署，你会考虑哪些工程问题？

- 假设模型供应商突然不可用，系统怎么降级？
- 假设金融客户要求每一次回答都可审计，你怎么设计 trace？
