# 产品经理专业术语清单

面向 **金融学背景、补充产品岗位语境** 的速查表：听到词能接上话即可，不必背定义。

## 一、需求与文档

| 术语 | 含义（极简） |
|------|------|
| **PRD**（Product Requirements Document） | 产品需求文档：写清背景、目标用户、功能范围、流程、规则、验收标准，给研发/测试对齐用。 |
| **BRD** | 商业需求文档：更偏「为什么要做、赚什么钱/省什么成本」，常比 PRD 更早、更宏观。 |
| **MRD** | 市场需求文档：市场机会、竞品、目标客群，介于战略和 PRD 之间。 |
| **User Story** | 用户故事：「作为某类用户，我想要...，以便...」，从用户价值写需求。 |
| **Acceptance Criteria（AC）** | 验收标准：怎样算「做完了」，可测试、可勾选，减少扯皮。 |
| **Use Case** | 用例：用户与系统交互的场景步骤，常带主流程、异常分支。 |
| **MVP**（Minimum Viable Product） | 最小可行产品：用最小功能验证核心价值，再迭代。 |
| **Scope / Scope Creep** | 范围 / 范围蔓延：做什么的边界；蔓延指需求越加越多导致延期。 |

## 二、规划与优先级

| 术语 | 含义（极简） |
|------|------|
| **Roadmap** | 路线图：未来一段时间「做什么、大概什么顺序」，常按季度或主题排。 |
| **Backlog** | 需求池/待办列表：还没做或排队的需求、任务。 |
| **Prioritization** | 优先级排序：在资源有限下决定先做谁后做谁。 |
| **MoSCoW** | 必须/应有/可有/暂不（Must/Should/Could/Won't）。 |
| **RICE** | Reach × Impact × Confidence / Effort，一种打分排序方法。 |
| **KANO** | 把需求分为基本型、期望型、兴奋型等，判断满意度影响。 |

## 三、敏捷与协作

| 术语 | 含义（极简） |
|------|------|
| **Agile / Scrum** | 短周期迭代交付、固定仪式（计划会、站会、评审、回顾）。 |
| **Sprint** | 迭代周期：常见 1-2 周。 |
| **PO**（Product Owner） | 对 Backlog 优先级和验收负责。 |
| **Scrum Master** | 保流程、扫障碍，一般不替 PO 定「做什么」。 |
| **Stand-up / Daily** | 每日站会，短同步进度与阻塞。 |
| **Retrospective** | 迭代回顾。 |
| **Velocity** | 团队速率，用于估算。 |
| **Spike** | 技术探针：短时验证不确定性。 |

## 四、体验与设计

| 术语 | 含义（极简） |
|------|------|
| **Persona** | 用户画像：典型用户类型及目标、痛点。 |
| **User Journey** | 用户旅程：从认知到使用到留存/流失的关键步骤与触点。 |
| **Wireframe** | 低保真页面结构图。 |
| **Prototype** | 可点击原型。 |
| **Usability Test** | 可用性测试。 |
| **Information Architecture（IA）** | 信息架构：内容分类与导航组织。 |
| **Edge Case** | 边界/异常场景。 |

## 五、数据与实验

| 术语 | 含义（极简） |
|------|------|
| **North Star Metric** | 北极星指标：最能代表长期价值的核心指标。 |
| **OKR** | 目标与关键结果。 |
| **Funnel** | 漏斗：曝光到转化的关键环节。 |
| **Cohort** | 同期群分析。 |
| **Retention** | 留存。 |
| **DAU / MAU** | 日活 / 月活。 |
| **A/B Test** | 对照实验。 |
| **埋点** | 行为事件采集。 |
| **Dashboard** | 指标看板。 |

## 六、商业化与增长

| 术语 | 含义（极简） |
|------|------|
| **PMF**（Product-Market Fit） | 产品与市场匹配。 |
| **LTV / CAC** | 用户生命周期价值 / 获客成本。 |
| **Churn** | 流失。 |
| **Onboarding** | 新用户引导。 |

## 七、B 端 / 平台 / 信息化

| 术语 | 含义（极简） |
|------|------|
| **B 端 / C 端 / G 端** | 对企业 / 对消费者 / 对政府。 |
| **Workflow** | 工作流：业务做事步骤。 |
| **RBAC** | 基于角色的权限控制。 |
| **Audit Log** | 审计日志。 |
| **SLA** | 服务等级协议。 |
| **SSO** | 单点登录。 |
| **Integration / API** | 系统集成/接口能力。 |

## 八、AI 产品

| 术语 | 含义（极简） |
|------|------|
| **RAG** | 检索增强生成：先检索再生成，降低胡编。 |
| **Prompt / System Prompt** | 提示词 / 系统提示。 |
| **Hallucination** | 幻觉：看似合理但事实错误。 |
| **Eval / Benchmark** | 评测与基准。 |
| **Guardrail** | 护栏：安全与合规限制。 |
| **MCP**（Model Context Protocol） | 统一连接工具与数据源的协议思路。 |
| **Agent** | 可规划并调用工具完成任务的智能体。 |
