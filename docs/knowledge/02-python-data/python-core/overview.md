### 三、Python 与数据处理

如果岗位要求会 Python，这部分通常会以笔试代码题、口头追问或者项目追问形式出现。

常见考点：

- Python 基础语法：列表、字典、函数、循环、条件判断
- 文件读写：`csv`、`excel`、`json`
- `pandas` 核心操作：读表、筛选、排序、重命名、去重、缺失值处理
- 数据清洗：异常值处理、字段标准化、类型转换、日期处理
- 合并与汇总：`merge`、`groupby`、`pivot_table`
- 时间序列基础处理：按日/周/月聚合、环比、同比、滚动统计
- 简单可视化：`matplotlib`、`seaborn`
- 代码规范意识：可读性、复用、调试思路

常见追问：

- `merge` 和 `concat` 的区别是什么？
- 缺失值常见处理方式有哪些？
- `groupby` 之后怎么恢复成普通表？
- 如何快速检查一列数据的异常情况？
