### 六、 机器学习与算法及其他

### 3. 机器学习模型知识点

- **XGBoost 原理**：
  - 本质是加法模型 + 梯度提升树，每一棵新树拟合前一轮损失函数的负梯度。
  - 关键增强点包括：二阶泰勒展开、正则化项、列采样、行采样、Shrinkage、缺失值默认方向处理。
  - 优点是能自动处理非线性与特征交互，且对表格数据往往很强。
- **XGBoost 用于股票数据时的特点**：
  - 适合多因子表格特征、非线性关系和弱交互挖掘。
  - 对异常值和缺失值相对鲁棒，但对**未来函数、标签泄漏、样本切分错误**极其敏感。
  - 股票数据噪声大、非平稳强，必须做滚动训练、定期重训和样本外验证。
- **LSTM 原理**：
  - 核心是记忆单元 `cell state` 与输入门、遗忘门、输出门。
  - 它可以在时间维度上保留重要历史信息，缓解普通 RNN 的梯度消失问题。
  - 适合处理顺序依赖较强的时序特征。
- **LSTM 与树模型对比**：
  - LSTM 优势：适合显式建模时序依赖，能利用长短期动态信息。
  - LSTM 劣势：训练成本高、调参复杂、对样本量和数据清洗要求更高、解释性较弱。
  - 树模型优势：对表格数据友好、训练更快、特征重要性更直观、通常更稳。
  - 树模型劣势：如果不手工构造时序特征，本身不直接建模序列顺序。
- **Attention 机制中的 Q / K / V**：
  - `Q`（Query）表示“我要找什么”。
  - `K`（Key）表示“我能提供什么索引信息”。
  - `V`（Value）表示“真正被聚合的内容”。
  - 计算流程：
    `Attention(Q,K,V) = softmax(QK^\top / \sqrt{d_k})V`
  - 本质是用 Query 和 Key 算相似度，再用相似度对 Value 做加权求和。
- **图神经网络（GNN）能否用于股票市场**：
  - 可以，关键在于如何定义图结构。
  - 节点可以是股票，边可以来自行业关系、供应链关系、共同持仓、价格相关性、新闻关联等。
  - GNN 适合建模“个股不是独立样本，而是存在关联传播”的情形。
  - 风险点在于图结构是否稳定、是否引入噪声边，以及是否真的优于简单基线。

#### 1. 经典题库与母题

- **绿皮书 / `A Practical Guide to Quantitative Finance Interviews*`*：
  - 这是很多量化岗面试的经典题库来源
  - 复习时不要只背答案，更重要的是按章节掌握母题和解题套路
- **常见 chapter2 型题目（脑筋急转弯 / 博弈 / 逻辑推理）**：
  - 四人过河（核心是找最优运输顺序，让“手电筒往返成本”最小）
  - 赛马问题（核心是通过分组比较逐步缩小候选集合，减少总比较次数）
  - 法老关 50 人 / 智者题（核心是构造公共策略，把有限信息转成可验证的编码规则）
  - 100 囚徒与帽子 / 抽屉问题（核心是利用排列结构、奇偶性或循环分解，把成功率从直觉值提升到最优）
  - 这类题通常考策略构造、信息利用和最优决策
- **常见 chapter3 型题目（相关系数与半正定矩阵）**：
  - 比如：已知 `corr(X,Y)=0.8`、`corr(Y,Z)=0.8`，求 `corr(X,Z)` 的范围（核心是把相关矩阵写出来，再用半正定约束推出可行区间）
  - 核心方法是利用相关矩阵必须是 **positive semidefinite**
  - 这类题非常适合和线代、协方差矩阵一起复习
- **常见 chapter4 型题目（概率论经典母题）**：
  - Poker hand（核心是组合计数，先分清样本空间，再数目标事件）
  - Chess tournament（核心是把比赛结果转成图或计数问题，再用对称性、期望或抽屉原理）
  - Dart game（核心是几何概率或条件概率，先画区域再算面积/积分）
  - Russian roulette（核心是条件概率与状态更新，关键信息是“已发生什么”会改变后验概率）
  - Meeting probability（核心是把“是否相遇”转成平面区域面积占比问题）
  - Probability of triangles（核心是把能构成三角形的条件写成不等式，再做几何或积分求概率）
  - Moment of normal distribution（核心是用矩母函数、递推、对称性或标准化来求矩）
  - Coupon collection（核心是分阶段看“还差多少种没收集到”，再把等待时间期望相加）
  - Random ants（核心是利用对称性，把复杂路径问题转成几个方向组合的计数）
  - 这些题很多你前面已经补过一部分，后续可以继续往题库里细化
- **chapter5 / coin triplets**：
  - 属于硬币串、模式出现、状态转移类问题
  - 一句话思路：先把“当前已经匹配到哪一段模式”定义成状态，再写递推或首次到达方程。
  - 常用方法是条件概率、递推、马尔可夫链和首次到达分析


### 机器学习在量化中的基础用法



### 1. 这一节里的机器学习，到底在做什么？

- 机器学习可以先粗略理解成：让模型从历史样本里学习“特征和结果之间的关系”，再去预测新样本。
- 在量化里，它不是魔法，而是另一种处理“已知信息能不能帮助预测未来结果”的方法。
- 所以前面的因子研究、统计回归和这一节，其实是同一条学习线上的不同阶段。

### 2. 什么是特征？什么是标签？

- 特征（feature）：模型用来做判断的输入信息
- 标签（label）：模型最终要预测的目标结果
- 在这一节里：
  - `momentum`、`volatility`、`value` 是特征
  - `label` 是标签

你可以先这样记：

- 特征是“模型看到的线索”
- 标签是“模型要猜的答案”

常见误区：

- 把未来信息偷偷放进特征里，这会导致模型看起来很准，但实际上不可用。

### 3. 为什么这里要先把列名放进 `feature_cols`？

- 因为机器学习常常不是只用一个特征，而是很多个特征一起用。
- 先把列名放进列表里，后面取列会更清楚，也方便增删特征。

极小例子：

```python
feature_cols = ["momentum", "volatility", "value"]
X = df[feature_cols]
```

### 4. 为什么标签常常要从连续收益变成 0/1？

- 因为这一节用的是分类模型。
- 分类模型不是预测具体赚多少，而是预测“属于哪一类”。
- 所以常见做法是把 `next_return > 0` 转成“上涨 / 不上涨”。

极小例子：

```python
df["label"] = (df["next_return"] > 0).astype(int)
```

相关概念：

- 回归任务：预测连续数值，比如收益率大小
- 分类任务：预测类别，比如涨或跌

### 5. 什么是训练集和测试集？为什么一定要拆开？

- 训练集：给模型学习用的数据
- 测试集：模型没见过、用来检验泛化能力的数据
- 如果训练和测试不分开，模型可能只是把样本记住了，看起来很准，但对新数据并不好用。

极小例子：

```python
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=42
)
```

常见误区：

- 在全量数据上先做完处理、再拆分，容易引入信息泄露。
- 只看训练集效果，不看测试集表现。

### 6. 多返回值接收在这里为什么重要？

- 因为很多机器学习函数一次会返回多个对象。
- 例如拆训练集/测试集时，会同时返回四个结果。
- 这和前面你学过的多变量解包是同一种语法思想。

### 7. `fit()`、`predict()`、`predict_proba()` 各自在做什么？

- `fit()`：让模型从训练数据里学习
- `predict()`：输出模型预测的类别结果
- `predict_proba()`：输出每个类别的概率，常用来衡量模型信心

极小例子：

```python
clf.fit(X_train, y_train)
y_pred = clf.predict(X_test)
y_prob = clf.predict_proba(X_test)[:, 1]
```

你可以先把它理解成：

- `fit` 是学习
- `predict` 是表态
- `predict_proba` 是表态时顺便告诉你“我有多确定”

### 8. 为什么要分步骤写，而不是一股脑连起来？

- 因为机器学习流程其实很长：
  - 准备特征
  - 准备标签
  - 划分训练测试
  - 训练模型
  - 做预测
  - 评估结果
- 分步骤写，既方便你理解，也方便排查哪一步出了问题。

### 9. 评价指标在回答什么问题？

- `accuracy`：整体预测对了多少
- `precision`：模型说“会涨”的里面，真的涨了多少
- `recall`：真正会涨的样本里，模型抓住了多少
- 这些指标是在从不同角度看模型表现。

常见误区：

- 只盯着准确率。量化里即使分类准确率不低，也不代表一定能赚钱，因为还要看收益大小、交易成本、样本分布等因素。

### 10. 标准化为什么会出现？

- 因为不同特征的量纲可能很不一样。
- 有些模型对特征尺度敏感，所以需要先把特征拉到相近尺度。
- 标准化不是让数据“更高级”，而是让模型更容易稳定学习。

极小例子：

```python
scaler = StandardScaler()
X_train_scaled = scaler.fit_transform(X_train)
X_test_scaled = scaler.transform(X_test)
```

特别要记住：

- `fit` 只在训练集上做
- 测试集只能 `transform`
- 否则容易把测试信息提前泄露给模型

### 11. 为什么这一节既有逻辑回归又有树模型？

- 逻辑回归适合帮助你理解最基础、最可解释的分类流程。
- 树模型让你感受：不同模型虽然结构不同，但机器学习流程本身是类似的。
- 这也是你以后学更复杂模型时最该保留的主线：先看流程，再看模型细节。

### 12. 这一节和前后内容怎么衔接？

- 前面的因子研究和统计回归，已经在训练你思考“特征和结果的关系”。
- 这一节是把这种思路推进到机器学习流程里。
- 后面你再看回测框架、组合分析时，会更容易意识到：模型预测只是研究链条的一部分，最后还要回到交易、成本和风险上。
