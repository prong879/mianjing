### 八、机器学习与数据挖掘基础

并不是所有数据分析岗都深考机器学习，但很多岗位会考基础认知，尤其是校招、笔试和偏算法分析的岗位。

常见考点：

- 监督学习与非监督学习
- 分类与回归
- 线性回归、逻辑回归
- 决策树、随机森林、`XGBoost` 的基础认知
- 聚类：`KMeans`
- 特征工程的基本概念
- 训练集、验证集、测试集
- 过拟合与欠拟合
- 常见评估指标：准确率、召回率、F1、AUC、RMSE

常见追问：

- 逻辑回归为什么能做分类？
- 决策树为什么容易过拟合？
- 分类问题为什么不能只看准确率？
