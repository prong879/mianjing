### 二、大模型基础与 LLM 调用

AI Agent 的核心能力来自大语言模型，但开发者需要理解模型的输入输出方式、能力边界和调用成本，而不只是会调接口。

常见考点：

- 大模型基本概念：`LLM`、`Token`、上下文窗口、温度参数、采样
- 模型能力边界：幻觉、上下文遗忘、数学不稳定、事实性错误
- 常见模型类型：通用对话模型、推理模型、多模态模型、Embedding 模型
- API 参数：`temperature`、`top_p`、`max_tokens`、`stream`
- 上下文管理：短上下文、长上下文、摘要压缩、关键信息保留
- 成本与延迟：Token 成本、首 token 延迟、吞吐量、并发限制
- 结构化输出：JSON 输出、Schema 约束、输出解析、重试修复

常见追问：

- `temperature` 调高或调低分别适合什么场景？
- 为什么大模型会产生幻觉？
- 上下文窗口越大是否一定越好？
- 如何让模型稳定输出可以被程序解析的 JSON？
