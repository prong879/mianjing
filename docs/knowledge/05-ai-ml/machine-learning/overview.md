### 八、机器学习与数据挖掘基础

并不是所有数据分析岗都深考机器学习，但很多岗位会考基础认知，尤其是校招、笔试和偏算法分析的岗位。

> https://zhuanlan.zhihu.com/p/664999177


常见考点：

- 监督学习（有监督学习依赖于预先标注好的训练数据集，例如天气预报）与非监督学习（无监督学习不依赖于预先标注好的训练数据集，例如用户分群）（监督学习是“有标签学映射”，非监督学习是“无标签找结构和模式”。）
- 分类与回归（分类预测离散类别，回归预测连续数值。）
- 线性回归、逻辑回归（线性回归拟合连续目标，逻辑回归输出概率并常用于二分类。）
- 决策树、随机森林、`XGBoost` 的基础认知（决策树靠规则分裂，随机森林用多树投票降方差，`XGBoost` 用逐步加树提升精度。）
- 聚类：`KMeans`（`KMeans` 通过迭代更新簇中心，把样本分到最近中心以最小化簇内距离。）
- 特征工程的基本概念（特征工程是把原始数据清洗、编码和变换成更利于模型学习的输入特征。）
- 训练集、验证集、测试集（训练集用于拟合参数，验证集用于调参与选模型，测试集用于最终泛化评估。）
- 过拟合与欠拟合（过拟合是训练好测试差、学到噪声，欠拟合是模型太简单、连训练规律都没学到。）
- 常见评估指标：准确率、召回率、F1、AUC、RMSE（准确率看整体命中，召回率看正类找回，`F1` 平衡精确率与召回率，`AUC` 看排序能力，`RMSE` 衡量回归误差量级。）

常见追问：

- 逻辑回归为什么能做分类？
- 决策树为什么容易过拟合？
- 分类问题为什么不能只看准确率？

### 面试高频知识点补充

#### 1. 分类变量编码方式

- **独热编码 (One-Hot)**：适合类别数不多的变量（如性别、设备类型）。简单、可解释、不引入顺序。但高基数类别会导致维度膨胀和特征稀疏。
- **Target Encoding**：用该类别对应的目标均值来编码（如某类目的平均转化率）。适合高基数类别，但必须做交叉验证或时间切分，避免标签泄露。
- **频次编码**：用类别出现次数或占比表示。适合表达热门/稀疏程度。
- **Embedding**：适合类别极多、样本量极大、深度学习模型允许的场景。

#### 2. 类别不平衡问题处理

- **评估指标**：看精确率、召回率、F1、AUC、PR-AUC。正样本极少时，PR-AUC 比 ROC-AUC 更敏感。不能只看准确率。
- **采样方法**：少数类过采样（如 SMOTE）、多数类欠采样。
- **模型权重**：给少数类更高权重（如 `class_weight`，XGBoost 的 `scale_pos_weight`）。
- **阈值调整**：根据业务目标调整决策阈值，更偏召回还是更偏精确。

#### 3. 模型上线与部署

- **特征可获得性**：训练特征线上是否实时/准实时可取，是否存未来信息泄露。
- **数据链路**：特征口径线上线下一致性，缺失/异常值处理。
- **服务性能**：推理时延、吞吐、稳定性。
- **监控**：特征漂移、预测分数漂移、核心业务指标。
- **迭代机制**：重训周期、灰度上线、回滚机制。

#### 4. 常见分类模型优缺点

- **逻辑回归**：简单、可解释、训练快，适合 baseline 和需要解释特征方向的场景。
- **决策树**：可解释性强，能处理非线性和特征交互，但容易过拟合。
- **随机森林**：多树集成，稳定性比单树好，抗噪声强，可输出特征重要性。
- **XGBoost / GBDT**：适合结构化表格数据，效果上限高，能处理复杂非线性，但需调参防过拟合。
- **朴素贝叶斯**：训练快，适合文本分类等高维稀疏场景，但有特征独立性强假设。
- **SVM**：适合中小样本、高维特征，但核函数计算慢，可解释性弱。



> **混淆矩阵**：它是一个“真实标签 × 预测标签”的计数表，用来查看分类器把样本分到了哪里。  
> 在二分类里通常是 `2×2`：
>
> - `TP`（真正）：真实为正、预测也为正（真实值符合预测）
> - `FP`（假正）：真实为负、但预测为正（误报）
> - `FN`（假负）：真实为正、但预测为负（漏报）
> - `TN`（真负）：真实为负、预测也为负（真实值符合预测）  
> 通过这四个数可以继续计算准确率、精确率、召回率、`F1` 等指标。
>
>   | 预测值 \ 真实值       | 正类 Positive (1) | 负类 Negative (0) |
>   | --------------- | --------------- | --------------- |
>   | 正类 Positive (1) | TP（真阳）          | FP（假阳）          |
>   | 负类 Negative (0) | FN（假阴）          | TN（真阴）          |
>
> 由此可以计算各种指标：
>
> 准确率：$Accuracy = (TP + TN) / (TP + FP + FN + TN) = Pr[\hat{y} = y]$
>
> 错误率：$Error Rate = 1 - Accuracy = (FP + FN) / (TP + FP + FN + TN) = Pr[\hat{y} != y]$
>
> 准确率+错误率=1
>
> 真阳率：$TPR = TP / (TP + FN) = Pr[\hat{y} = 1 | y = 1]$
>
> 真阴率：$TNR = TN / (TN + FP) = Pr[\hat{y} = 0 | y = 0]$
>
> 假阳率：$FPR = FP / (FP + TN) = Pr[\hat{y} = 1 | y = 0]$
>
> 假阴率：$FNR = FN / (FN + TP) = Pr[\hat{y} = 0 | y = 1]$
>
> 模型精度：在预测值为1 的样本中，有多少样本真实值也是1，也就是预测正确的样本占预测为1的样本的比例，$Precision = TP / (TP + FP)$
>
> F1分数：$F1 = 2 * \frac{Precision * Recall}{Precision + Recall}$
