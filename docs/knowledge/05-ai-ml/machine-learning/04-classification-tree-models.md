## 8. 逻辑回归 (Logistic Regression)
虽然名字里带有“回归”，但逻辑回归实际上是专门用来解决**分类问题**（预测离散标签，如“是/否”、“猫/狗”）的经典算法。

- **为什么不能用线性回归做分类？**
  线性回归输出的是负无穷到正无穷的任意实数，而分类任务需要的是概率（0到1之间）。如果强制用线性回归，不仅输出范围失控，而且极易受到异常值的严重干扰，导致决策边界被拉偏。
- **Sigmoid 函数与概率映射**
  逻辑回归在线性回归的基础上，套上了一个“变形器”——Sigmoid 函数：$\sigma(z) = \frac{1}{1 + e^{-z}}$。
  它能将线性回归的输出（任意实数）完美映射到 $(0, 1)$ 区间，赋予其概率含义。当输出大于 0.5 时判为正类，小于 0.5 判为负类。此外，Sigmoid 函数连续平滑、处处可导，且导数计算极其简便（$\sigma'(x) = \sigma(x)(1-\sigma(x))$），非常适合梯度下降。
- **交叉熵损失函数 (Cross Entropy)**
  如果将 MSE 用于逻辑回归，由于 Sigmoid 的非线性，损失函数会变得坑坑洼洼（非凸函数），极易陷入局部最优或梯度消失。
  基于最大似然估计（MLE）推导出的**交叉熵损失函数**完美解决了这个问题。其核心思想是：当真实标签为 1 时，预测概率越接近 1 损失越小，越接近 0 惩罚极大（趋于无穷）；反之亦然。交叉熵是一个严格的凸函数，确保梯度下降能找到全局最优。
- **Softmax 函数与多分类**
  对于多分类问题（如手写数字 0-9 识别），只需将 Sigmoid 升级为 Softmax 函数。它为每个类别计算一个独立得分，并转化为概率分布，确保所有类别概率之和为 1。逻辑回归+Softmax 实际上就是现代神经网络中最常用的输出层结构。

## 9. 分类模型评估指标
在分类任务中，仅看“准确率 (Accuracy)”往往具有欺骗性（例如在 99% 都是良性肿瘤的数据集中，全猜良性也有 99% 的准确率）。我们需要更细致的指标：

- **混淆矩阵 (Confusion Matrix)**
  将预测结果与真实结果交叉比对，分为四种情况：
  - **TP (True Positive)**：真阳性（实际正，预测正）
  - **TN (True Negative)**：真阴性（实际负，预测负）
  - **FP (False Positive)**：假阳性 / 误报（实际负，预测正）
  - **FN (False Negative)**：假阴性 / 漏报（实际正，预测负）
  在不同业务场景中代价不同。例如医疗肿瘤筛查中，漏报（FN）的代价远大于误报（FP）。
- **核心评估指标**
  - **精确率 (Precision)**：$TP / (TP + FP)$。预测为正的样本中，真正为正的比例。（预测的质量）
  - **召回率 (Recall)**：$TP / (TP + FN)$。实际为正的样本中，被成功找出来的比例。（覆盖的能力）
  - **F1-Score**：精确率和召回率的调和平均数，综合衡量模型表现。
- **阈值选择工具：ROC 曲线与 AUC 面积**
  改变决策阈值（如从 0.5 降到 0.3）会改变精确率和召回率。ROC 曲线的横轴是假正率（误报率），纵轴是真正率（召回率），描绘了不同阈值下模型的表现。
  **AUC (Area Under Curve)** 是 ROC 曲线下的面积。AUC 越大，说明模型区分正负样本的能力越强，泛化能力越好。AUC=0.5 相当于随机瞎猜。
  **AUC 的物理意义**：随机抽取一个正样本和一个负样本，模型给正样本打分高于负样本打分的概率。AUC 对类别不平衡非常鲁棒。
  *(注：在面对极度类别不平衡数据时，准确率会失效，除了关注 ROC/AUC，还常通过调整类别权重如 `class_weight='balanced'` 来处理。)*

## 10. 决策树 (Decision Trees)
决策树是最符合人类直觉的非线性机器学习算法，它模仿人类决策时“层层提问”的方式，将数据按照特征进行递归分裂，最终形成倒立的树状结构。

- **直观概念与分裂条件**
  决策树包含**根节点**（初始全部数据）、**内部节点**（特征提问）、**分支**（答案路径）和**叶子节点**（最终决策结果）。它的最大优势是**极强的可解释性**，在金融放贷、医疗诊断等需要明确证据链的场景中无可替代。对于连续型变量，决策树会将其排序，取相邻值的均值作为候选分裂点，计算纯度增益最大的点进行分裂。
- **节点划分准则脉络：纯度**
  模型如何选择最佳的分裂特征？核心是追求节点分裂后的“纯度”最高（即同一节点内尽量属于同一类别）。
  - **信息增益 (ID3 算法)**：基于信息熵，衡量分裂前后混乱程度的下降量。缺点是计算涉及对数，较慢，且容易偏向取值较多的特征。
  - **增益比 (C4.5 算法)**：对 ID3 的改进，克服了偏向取值多特征的缺点。
  - **基尼指数 (CART 算法 / Gini Impurity)**：衡量随机抽取两个样本类别不一致的概率。基尼系数越小节点越纯。
  - **实务与 sklearn**：工业界和 Scikit-Learn 默认使用基尼指数，因为它只涉及加法和乘法，计算极快；而信息增益容易偏向取值多的特征且计算慢。
- **决策树的剪枝**
  决策树的致命缺陷是**极易过拟合**。如果不加限制，它会肆意生长，直到把训练集中的每一个噪声都强行分对。
  - **预剪枝 (Pre-pruning)**：在树生长过程中提前设定规则（如限制最大深度 `max_depth`，或限制叶子节点最少样本数）。实现简单计算量小，工业界普遍采用。
  - **后剪枝 (Post-pruning)**：先让树完全生长，再自底向上剪掉影响小的分支。效果好但计算成本极高。
## 11. 经典监督算法补充（与树、逻辑回归并列的基线）
除了树模型，还有几类经典的分类算法，它们在特定场景下依然发挥着重要作用，常作为基线模型。

- **K 近邻算法 (KNN)**
  - **核心思想**：“近朱者赤，近墨者黑”。属于**惰性学习**，没有显式的训练过程，预测时寻找距离最近的 $K$ 个样本进行投票（分类）或取平均（回归）。
  - **关键点**：预测成本高（需要计算与所有样本的距离）、对特征尺度极其敏感（**必须配合特征缩放**）。
- **支持向量机 (SVM)**
  - **核心思想**：在特征空间中寻找一个超平面，将不同类别的样本分开，并使得离超平面最近的样本点（支持向量）到超平面的距离最大化（**最大间隔**）。
  - **关键点**：通过**核函数**（如 RBF）处理非线性问题；引入**松弛变量**处理噪声。在中小规模数据中极其常见且表现优异。
- **朴素贝叶斯 (Naive Bayes)**
  - **核心思想**：基于贝叶斯定理的**生成式**概率模型。
  - **“朴素”的含义**：假设特征之间是**条件独立**的。
  - **关键点**：逻辑简单、训练极快，是文本垃圾邮件过滤、情感分析等高频考点的首选算法。

## 🎯 实战案例：乳腺癌诊断与鸢尾花分类
**案例 1：乳腺癌肿瘤良恶性诊断 (二分类与评估指标)**
- **背景**：根据肿瘤的细胞核特征预测其是良性还是恶性。在医疗场景中，漏报（将恶性误判为良性）的代价极大。
- **操作**：使用逻辑回归（Logistic Regression）进行预测。重点不在于准确率，而是打印混淆矩阵和分类报告（包含 Precision, Recall, F1），并绘制 ROC 曲线计算 AUC 值。通过调整决策阈值（如从 0.5 降到 0.3）来强行提高召回率（减少漏报）。

**案例 2：鸢尾花品种识别 (多分类与树模型/SVM)**
- **背景**：根据花萼和花瓣的长宽，将鸢尾花分类为三个品种（山鸢尾、变色鸢尾、维吉尼亚鸢尾）。
- **操作**：
  - 使用决策树（DecisionTreeClassifier）进行训练，并利用 `plot_tree` 将树状规则可视化，直观理解基尼系数的下降过程。
  - 对比使用 KNN 和 SVM（RBF核）在二维特征空间中绘制非线性决策边界。

**核心伪代码/API 展示**（完整可执行代码见配套 Jupyter Notebook）：
```python
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import classification_report, roc_auc_score
from sklearn.tree import DecisionTreeClassifier, plot_tree
import matplotlib.pyplot as plt

# --- 案例 1：逻辑回归与评估指标 ---
log_reg = LogisticRegression(class_weight='balanced') # 处理类别不平衡
log_reg.fit(X_train, y_train)
y_prob = log_reg.predict_proba(X_test)[:, 1] # 获取预测为正类的概率
y_pred = log_reg.predict(X_test)

print(classification_report(y_test, y_pred)) # 打印精确率、召回率、F1
print(f"AUC Score: {roc_auc_score(y_test, y_prob):.3f}")

# --- 案例 2：决策树训练与可视化 ---
tree_clf = DecisionTreeClassifier(max_depth=3, random_state=42)
tree_clf.fit(X_train_iris, y_train_iris)

plt.figure(figsize=(12, 8))
plot_tree(tree_clf, filled=True, feature_names=['sepal_len', 'sepal_wid', 'petal_len', 'petal_wid'])
```
