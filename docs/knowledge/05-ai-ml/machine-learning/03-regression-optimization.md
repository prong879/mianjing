# 模块三：回归问题与模型优化基础 (Regression & Optimization)

## 5. 线性回归 (Linear Regression)
线性回归是机器学习中最经典、最基础的模型，它通过构建线性方程来拟合数据的内在分布规律，从而实现对**连续数值**的预测（如房价）。

- **线性模型的数学定义**：在数学中，“线性”意味着输入和输出之间满足可加性和齐次性（按比例变化）。模型公式通常表示为 $\hat{y} = WX + b$，其中 $W$ 是权重（斜率），$b$ 是偏置（截距）。注意：线性回归指的是**对参数（$W$）是线性的**，而不是对特征本身必须是线性的。
- **“回归”词源**：源自统计学中的“回归均值”现象（极端身高父母的孩子身高倾向于向群体平均值靠拢）。在机器学习中，引申为寻找变量间映射关系以预测连续数值的过程。
- **最小二乘法 (OLS)**：在数据量较小且特征较少时，可以通过最小二乘法直接通过矩阵运算一次性求出参数的解析解。
- **多项式回归延伸**：当现实数据并非沿直线分布时，可以引入特征的高次项（如 $X^2, X^3$）。虽然特征变成了非线性，但模型对参数 $W$ 依然是线性的，因此多项式回归本质上仍属于广义的线性回归范畴。

## 6. 梯度下降 (Gradient Descent)
当数据量庞大时，无法直接求出解析解，模型需要通过不断试错来寻找最优参数。梯度下降就是指导模型“如何调整参数”的核心优化算法。

- **损失函数与 MSE**：为了衡量模型预测的准不准，我们引入损失函数。线性回归最常用的是均方误差（MSE）。MSE 通过对预测误差求平方，不仅消弭了正负号的抵消问题，还能放大较大的误差，对偏离严重的预测施加更大的惩罚。
- **导数、偏导与梯度**：
  - 导数表示函数的变化率；偏导数表示多元函数中某一个参数对整体结果的影响。
  - **梯度**是所有偏导数组成的向量，它指向函数值**增长最快**的方向。
  - 梯度下降的原理就是让参数沿着梯度的**反方向**（即下降最快的方向）小步移动，最终逼近损失函数的最低点。
- **链式法则**：在计算复杂嵌套函数（如损失函数嵌套了预测函数）的偏导数时，依赖微积分中的链式法则。这也是深度学习中反向传播（Backpropagation）的数学基础。
- **学习率 (Learning Rate)**：决定了参数每次更新的“步幅”。学习率过小会导致收敛极慢，容易陷入局部最优；学习率过大则会导致参数在最低点两侧反复震荡，甚至出现**梯度爆炸**（误差越来越大）。
- **变体与优化器演进**：
  - **批量梯度下降 (BGD)**：每次使用全部数据计算梯度，精确但极慢。
  - **随机梯度下降 (SGD)**：每次只用一条数据，极快但噪声大、震荡剧烈。
  - **小批量梯度下降 (Mini-Batch GD)**：每次随机抽取一小批（如 64 或 128 条）数据计算，兼顾了精度与效率，支持 GPU 并行，是目前的主流。
  - **优化器演进**：为了解决手工设置学习率的难题，业界演进出了动量法（Momentum，引入惯性冲出局部最优）、RMSprop，以及集大成者 **Adam 优化器**。Adam 能够为每个参数自适应地调整学习率，跑得快且稳，是深度学习的默认首选。

## 7. 模型评估与诊断 (Evaluation & Diagnostics)
训练出模型后，需要科学的指标和方法来评估其好坏，并诊断存在的问题。

- **基线模型 (Baseline)**：在深入优化前，先快速建立一个简单的模型作为参考系。后续所有的优化效果都应与 Baseline 进行对比。
- **线性评估指标**：
  - **MAE (平均绝对误差)**：预测值与真实值差值的绝对值平均，业务含义直观，对异常值不敏感。
  - **MSE (均方误差)**：误差平方的平均，放大极端误差，常作损失函数。
  - **RMSE (均方根误差)**：MSE 开根号，量纲与目标变量一致，兼顾了业务解释性和对大偏差的敏感性。
  - **R² (决定系数)**：衡量模型比“直接用均值瞎猜”好多少。越接近 1 模型越完美，等于 0 说明和瞎猜无异，小于 0 说明模型存在严重 Bug。
- **模型诊断工具**：
  - **残差分析**：残差即真实值减预测值。通过绘制残差散点图和直方图，观察残差是否在 0 附近均匀波动。若残差呈现明显偏态或随预测值增大而发散，说明模型未能捕获某些关键规律。
  - **K折交叉验证 (K-Fold CV)**：将数据分成 K 份，轮流用 1 份测试、K-1 份训练。可有效消除数据划分带来的运气成分，评估模型的稳定性。
- **欠拟合 (Underfitting) 与过拟合 (Overfitting)**：
  - **偏差与方差权衡**：欠拟合表现为高偏差（学渣，连训练集都没学好）；过拟合表现为高方差（书呆子，死记硬背了训练集的噪声，测试集表现极差）。
  - **诊断**：通过绘制**学习曲线**（观察训练误差和验证误差随样本量增加的变化）。若两者误差都很高，为欠拟合；若训练误差极低但验证误差极高且不收敛，为过拟合。
  - **解决欠拟合**：做加法。增加模型复杂度（如使用多项式回归或树模型）、增加特征交叉扩维、增加训练轮数、减小正则化惩罚。
  - **解决过拟合**：做减法。增加训练数据、手工剔除冗余特征、早停法 (Early Stopping)、引入 Dropout（深度学习），以及最常用的**正则化**。
    - **L2 正则化 (Ridge / 岭回归)**：惩罚权重的平方和，使所有参数均匀变小趋近于0，模型变得平滑稳定。
    - **L1 正则化 (Lasso / 套索回归)**：惩罚权重的绝对值和，倾向于将不重要特征的权重直接压缩为0，自带特征选择功能。
