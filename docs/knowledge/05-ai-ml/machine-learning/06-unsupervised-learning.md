## 13. K-Means 聚类 (Clustering)
在现实业务中，获取带有标签的数据成本极高。无监督学习不需要标签，而是让机器自行探索数据内部的隐藏结构。聚类算法旨在将相似的数据自动分到同一个组中（“物以类聚”）。

- **聚类目标函数与距离度量**
  K-Means 的核心目标是最小化**簇内平方和 (SSE)**，即让同一个簇内的数据点尽可能紧密地围绕在簇中心周围。
  - 距离度量以**欧氏距离**（两点间的直线距离）为主。
  - 对比理解：**曼哈顿距离**（城市街区距离，即各维度绝对值差的总和）在某些高维稀疏特征或异常值较多的场景下表现更稳健。
- **K 值的选择：肘部法则与轮廓系数**
  K-Means 需要人为指定分为几个簇（K值）。
  - **肘部法则 (Elbow Method)**：绘制不同 K 值对应的 SSE 曲线，当曲线出现类似“手肘”的拐点时，该拐点即为最佳 K 值。
  - **轮廓系数 (Silhouette Coefficient)**：综合衡量簇内紧密度和簇间分离度，值越接近 1 聚类效果越好，可作为选择 K 值的辅助指标。
- **局限性与改进**
  - **局限性**：K-Means 假设簇是凸的（球形簇），对非球形分布的数据效果差；对数据的尺度（量纲）极其敏感（必须先做标准化）；对异常值非常敏感（因为均值容易被极值拉偏，可使用 **K-Medians** 缓解）。
  - **K-Means++ 改进**：优化了初始中心点的选择策略，使得初始中心点尽可能互相远离，避免陷入糟糕的局部最优。
  - **多次初始化 (n_init)**：算法默认会运行多次（如 10 次）不同的随机初始化，最终选取 SSE 最小的那次结果。
  - **Mini-batch K-Means**：在海量数据下，每次只抽取一小批数据更新中心点，极大地加速了聚类过程。
- **典型应用**：电商平台的用户画像预分群（价格敏感型、品牌忠诚型等）、图像颜色量化压缩。
- **选修扩展**：若需抵抗异常值，可使用 K-medoids（中心点聚类）；若处理非球形或密度不均的数据，可使用 DBSCAN（密度聚类）；还有无需预设 K 值的层次聚类。

## 14. PCA 主成分分析 (Dimensionality Reduction)
随着特征数量的增加，数据分析会面临严重的“维度灾难”。降维算法的目标是在尽量不丢失关键信息的前提下，极大地简化数据集。

- **维度灾难概念**
  在高维空间中，数据变得极度稀疏，传统的距离度量（如欧式距离）失效；同时，特征之间往往存在强烈的多重共线性（即多个特征表达相似的含义，如“距离地铁距离”和“地段评分”），这会严重消耗计算资源并干扰模型。
- **特征选择 vs 特征提取**
  - 特征选择：直接丢弃某些特征（如 Lasso 正则化）。
  - 特征提取：PCA 属于特征提取，它将原始的高维特征通过**线性组合**投影到一个新的低维正交空间中，生成全新的特征（主成分）。
- **计算核心**
  PCA 的底层数学过程包括：数据去中心化 -> 计算协方差矩阵（使用 Bessel 修正） -> 进行特征值分解。特征值越大的方向，说明数据在该方向上的方差越大，包含的信息量就越多。
- **超参数选取**
  PCA 的核心参数是保留多少个主成分。通常通过设定**解释方差率累计阈值**（如保留累计贡献率达到 95% 的主成分）来自动决定降维后的维度。
- **实战组合**
  在工业界，常采用组合拳：先用随机森林的特征重要性筛选掉纯噪声特征，然后再用 PCA 进行降维，彻底消除特征间的共线性，从而提升后续监督学习模型的训练效率。
- **局限性**
  PCA 基于线性假设，无法捕获非线性流形结构（对于非线性降维，通常需要使用 **t-SNE** 或 **UMAP**）；降维后的新特征是原始特征的线性组合，失去了原有的业务可解释性；此外，PCA 基于方差最大化，因此极度受异常值干扰（使用前需处理异常值并做标准化）。

## 🎯 实战案例：电商用户画像聚类与高维数据降维
**案例背景**：给定一批电商用户的消费行为数据（如浏览时长、购买频次、客单价等），在没有任何标签的情况下，我们需要将用户分为几个群体（如价格敏感型、品牌忠诚型），以便进行精准营销。

**核心操作步骤**：
1. **数据标准化**：K-Means 和 PCA 都对数据的量纲极其敏感，必须先使用 `StandardScaler` 进行标准化。
2. **K-Means 聚类与肘部法则**：
   - 循环尝试不同的 K 值（如 1 到 10），记录每次的 SSE（簇内平方和）。
   - 绘制 K 值与 SSE 的折线图，寻找“手肘”处的拐点，确定最佳的分类数量（假设最佳 K=3）。
   - 使用最佳 K 值重新训练模型，获取每个用户的群体标签。
3. **PCA 降维与可视化**：
   - 用户的行为特征可能有 10 维，无法直接在平面上画图。
   - 使用 PCA 将 10 维特征降维到 2 维（提取前两个主成分）。
   - 将降维后的二维数据绘制成散点图，并用 K-Means 预测的群体标签进行着色，直观查看聚类效果。

**核心伪代码/API 展示**（完整可执行代码见配套 Jupyter Notebook）：
```python
from sklearn.cluster import KMeans
from sklearn.decomposition import PCA
from sklearn.preprocessing import StandardScaler
import matplotlib.pyplot as plt

# 1. 必须先进行标准化
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)

# 2. K-Means 聚类 (假设通过肘部法则确定 K=3)
kmeans = KMeans(n_clusters=3, random_state=42, n_init='auto')
cluster_labels = kmeans.fit_predict(X_scaled)

# 3. PCA 降维 (降至 2 维以便可视化)
pca = PCA(n_components=2)
X_pca = pca.fit_transform(X_scaled)
print(f"累积方差贡献率: {sum(pca.explained_variance_ratio_):.2f}")

# 4. 可视化聚类结果
plt.scatter(X_pca[:, 0], X_pca[:, 1], c=cluster_labels, cmap='viridis', alpha=0.6)
plt.xlabel('Principal Component 1')
plt.ylabel('Principal Component 2')
plt.title('Customer Segmentation (PCA Reduced)')
plt.show()
```
