### 五、RAG 与知识库系统

RAG 是 Agent 开发里最常见的落地形态之一，用来解决模型不了解私有知识、知识更新滞后、回答需要引用来源等问题。

常见考点：

- RAG 基本流程：文档导入、切分、向量化、召回、重排、生成答案
- 文档解析：PDF、Word、网页、Markdown、表格、图片 OCR
- Chunk 切分：按长度、标题、语义、段落结构切分
- Embedding：文本向量化、语义相似度、向量维度
- 向量数据库：`FAISS`、`Milvus`、`Chroma`、`Pinecone`
- 检索策略：关键词检索、向量检索、混合检索、Metadata 过滤
- Rerank：对召回结果二次排序，提高相关性
- 引用溯源：答案附带文档来源、页码、段落
- RAG 评估：召回率、相关性、忠实度、答案完整性

常见追问：

- RAG 为什么能减少幻觉？
- Chunk 太大或太小分别有什么问题？
- 向量检索和关键词检索有什么区别？
- 用户问的问题在知识库里没有答案时，系统应该怎么回答？
