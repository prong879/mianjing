### 一、编程基础与工程能力

AI Agent 开发本质上还是软件工程问题。面试中不会只问“大模型会不会用”，还会看你能不能把模型、工具、数据、接口和业务流程稳定地组织起来。

常见考点：

- Python 基础：函数、类、异常处理、文件读写、虚拟环境、包管理
- Web 后端基础：`FastAPI`、`Flask`、接口设计、请求响应、参数校验
- 异步与并发：`async/await`、任务队列、流式输出、超时控制
- 数据结构：列表、字典、队列、树、图、状态机
- 工程规范：模块拆分、日志、配置管理、错误处理、单元测试
- API 调用：鉴权、重试、限流、超时、错误码、幂等性
- Git 与协作：分支、提交、代码 Review、需求拆解

常见追问：

- 为什么 Agent 应用更容易遇到超时、重试和状态不一致问题？
- 普通同步接口和流式接口在用户体验上有什么区别？
- 如果大模型调用失败，系统应该怎么降级？
- 如何设计一个可维护的 Agent 服务目录结构？
