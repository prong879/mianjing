### 十一、部署、性能与成本优化

Agent 原型做出来不难，难的是稳定、低成本、可监控地跑起来。工程落地岗位经常会追问这部分。

常见考点：

- 服务部署：本地开发、云服务器、容器化、环境变量
- 模型调用性能：并发、限流、超时、排队
- 流式响应：提升用户感知速度
- 缓存：Prompt 缓存、检索缓存、工具结果缓存
- 成本优化：减少无效上下文、压缩历史消息、选择合适模型
- 多模型路由：简单任务用小模型，复杂任务用强模型
- 任务队列：长任务异步执行、后台处理、进度通知
- 监控指标：响应时间、错误率、Token 用量、工具成功率
- 灰度发布：小流量验证 Prompt 或模型版本变更

常见追问：

- 如何降低一个 Agent 应用的调用成本？
- 为什么长任务不适合一直阻塞在 HTTP 请求里？
- 如何监控线上 Agent 的质量和稳定性？
- 模型升级后，为什么需要回归测试？
