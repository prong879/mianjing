### 九、评估、测试与可观测性

AI Agent 的输出不完全确定，传统“输入固定、输出固定”的测试方式不够用，所以需要专门的评估体系和线上观测能力。

常见考点：

- 单元测试：工具函数、参数校验、输出解析
- Prompt 测试：典型问题集、边界问题、恶意输入
- RAG 评估：召回准确性、答案忠实度、引用准确性
- Agent 评估：任务完成率、步骤正确率、工具调用成功率
- 人工评测：标注标准、打分维度、一致性
- 自动评测：LLM-as-a-Judge、规则校验、黄金数据集
- 可观测性：日志、Trace、Token 消耗、延迟、错误率
- 线上反馈：点赞点踩、用户纠错、失败案例回流

常见追问：

- Agent 应用如何做测试？
- 怎么判断一个 RAG 系统回答得好不好？
- 为什么只看最终答案不够，还要看中间调用链路？
- LLM-as-a-Judge 有什么局限？
