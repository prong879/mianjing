### 3. 机器学习模型知识点

- **XGBoost 原理**：
  - 本质是加法模型 + 梯度提升树，每一棵新树拟合前一轮损失函数的负梯度。
  - 关键增强点包括：二阶泰勒展开、正则化项、列采样、行采样、Shrinkage、缺失值默认方向处理。
  - 优点是能自动处理非线性与特征交互，且对表格数据往往很强。
- **XGBoost 用于股票数据时的特点**：
  - 适合多因子表格特征、非线性关系和弱交互挖掘。
  - 对异常值和缺失值相对鲁棒，但对**未来函数、标签泄漏、样本切分错误**极其敏感。
  - 股票数据噪声大、非平稳强，必须做滚动训练、定期重训和样本外验证。
- **LSTM 原理**：
  - 核心是记忆单元 `cell state` 与输入门、遗忘门、输出门。
  - 它可以在时间维度上保留重要历史信息，缓解普通 RNN 的梯度消失问题。
  - 适合处理顺序依赖较强的时序特征。
- **LSTM 与树模型对比**：
  - LSTM 优势：适合显式建模时序依赖，能利用长短期动态信息。
  - LSTM 劣势：训练成本高、调参复杂、对样本量和数据清洗要求更高、解释性较弱。
  - 树模型优势：对表格数据友好、训练更快、特征重要性更直观、通常更稳。
  - 树模型劣势：如果不手工构造时序特征，本身不直接建模序列顺序。
- **Attention 机制中的 Q / K / V**：
  - `Q`（Query）表示“我要找什么”。
  - `K`（Key）表示“我能提供什么索引信息”。
  - `V`（Value）表示“真正被聚合的内容”。
  - 计算流程：
    `Attention(Q,K,V) = softmax(QK^\top / \sqrt{d_k})V`
  - 本质是用 Query 和 Key 算相似度，再用相似度对 Value 做加权求和。
- **图神经网络（GNN）能否用于股票市场**：
  - 可以，关键在于如何定义图结构。
  - 节点可以是股票，边可以来自行业关系、供应链关系、共同持仓、价格相关性、新闻关联等。
  - GNN 适合建模“个股不是独立样本，而是存在关联传播”的情形。
  - 风险点在于图结构是否稳定、是否引入噪声边，以及是否真的优于简单基线。

#### 1. 经典题库与母题

- **绿皮书 / `A Practical Guide to Quantitative Finance Interviews*`*：
  - 这是很多量化岗面试的经典题库来源
  - 复习时不要只背答案，更重要的是按章节掌握母题和解题套路
- **常见 chapter2 型题目（脑筋急转弯 / 博弈 / 逻辑推理）**：
  - 四人过河（核心是找最优运输顺序，让“手电筒往返成本”最小）
  - 赛马问题（核心是通过分组比较逐步缩小候选集合，减少总比较次数）
  - 法老关 50 人 / 智者题（核心是构造公共策略，把有限信息转成可验证的编码规则）
  - 100 囚徒与帽子 / 抽屉问题（核心是利用排列结构、奇偶性或循环分解，把成功率从直觉值提升到最优）
  - 这类题通常考策略构造、信息利用和最优决策
- **常见 chapter3 型题目（相关系数与半正定矩阵）**：
  - 比如：已知 `corr(X,Y)=0.8`、`corr(Y,Z)=0.8`，求 `corr(X,Z)` 的范围（核心是把相关矩阵写出来，再用半正定约束推出可行区间）
  - 核心方法是利用相关矩阵必须是 **positive semidefinite**
  - 这类题非常适合和线代、协方差矩阵一起复习
- **常见 chapter4 型题目（概率论经典母题）**：
  - Poker hand（核心是组合计数，先分清样本空间，再数目标事件）
  - Chess tournament（核心是把比赛结果转成图或计数问题，再用对称性、期望或抽屉原理）
  - Dart game（核心是几何概率或条件概率，先画区域再算面积/积分）
  - Russian roulette（核心是条件概率与状态更新，关键信息是“已发生什么”会改变后验概率）
  - Meeting probability（核心是把“是否相遇”转成平面区域面积占比问题）
  - Probability of triangles（核心是把能构成三角形的条件写成不等式，再做几何或积分求概率）
  - Moment of normal distribution（核心是用矩母函数、递推、对称性或标准化来求矩）
  - Coupon collection（核心是分阶段看“还差多少种没收集到”，再把等待时间期望相加）
  - Random ants（核心是利用对称性，把复杂路径问题转成几个方向组合的计数）
  - 这些题很多你前面已经补过一部分，后续可以继续往题库里细化
- **chapter5 / coin triplets**：
  - 属于硬币串、模式出现、状态转移类问题
  - 一句话思路：先把“当前已经匹配到哪一段模式”定义成状态，再写递推或首次到达方程。
  - 常用方法是条件概率、递推、马尔可夫链和首次到达分析
