### 五、 数学与统计学

### 1. 概率统计与笔试计算题

- **联合正态/多元正态分布概率**：
  - 高频考法是给出二维正态或多元正态变量，要求你根据均值向量、协方差矩阵、相关系数求某个区域概率，或对线性组合做标准化。
  - 核心知识点：边缘分布、条件分布、线性变换后仍服从正态、协方差矩阵正定、相关系数与标准化。
  - 如果题目里出现复数形式，也往往是把实部、虚部分开看作二维正态来处理。
- **投资组合风险计算**：
  - 组合方差公式：$\sigma_p^2 = w^\top \Sigma w$。
  - 二资产情形：$\sigma_p^2 = w_1^2\sigma_1^2 + w_2^2\sigma_2^2 + 2w_1w_2\mathrm{Cov}(r_1,r_2)$。
  - 标准差才是“风险”的直观量，但笔试往往先算方差再开方。
- **数组方差的 O(n) 计算**：
  - 一趟扫描即可完成，经典做法是 **Welford 在线算法**。
  - 更新公式：
    - `count += 1`
    - `delta = x - mean`
    - `mean += delta / count`
    - `M2 += delta * (x - mean)`
    - 最终样本方差 `M2 / (count - 1)`，总体方差 `M2 / count`
  - 优点是时间复杂度 O(n)、空间复杂度 O(1)、数值稳定性优于“先求均值再求平方和”。
- **连续三次正面的期望**：
  - 这是“等待连续成功串出现”的经典马尔可夫链/状态转移题。
  - 常见做法是按“当前已经连续出现了多少次正面”来设状态。记：
    - $E_0$：当前没有连续正面时，到首次出现 `HHH` 还需要的期望次数
    - $E_1$：当前已经连续出现 `1` 次正面时的期望次数
    - $E_2$：当前已经连续出现 `2` 次正面时的期望次数
    - 到达连续 `3` 次正面后停止，所以 $E_3 = 0$
  - 根据下一次抛掷结果列状态转移方程：
    $$
    E_0 = 1 + pE_1 + (1-p)E_0
    $$
    $$
    E_1 = 1 + pE_2 + (1-p)E_0
    $$
    $$
    E_2 = 1 + pE_3 + (1-p)E_0 = 1 + (1-p)E_0
    $$
  - 这里每个式子前面的 `1` 表示“先抛一次”，后面再根据抛到正面或反面进入不同状态。
  - 解这组方程后可得，从初始状态开始的期望抛掷次数为：
    $$
    \mathbb{E}[T] = E_0 = \frac{1}{p} + \frac{1}{p^2} + \frac{1}{p^3}
    $$
  - 当 `p = 0.5` 时：
    $$
    \mathbb{E}[T] = 2 + 4 + 8 = 14
    $$
  - 这类题的通用思路是：**把“已经连续成功了几次”定义成状态，再写期望递推方程。**
- **家庭一直生到第一个女孩为止**：
  - 若生女孩概率为 `q`，则每个家庭最终一定会在第一次生出女孩时停止，所以**每个家庭最终恰好有 1 个女孩**。
  - 设停止前生出的男孩数为 `B`，则
    $$
    \mathbb{P}(B=k)=(1-q)^k q,\qquad k=0,1,2,\dots
    $$
    这就是“第一次成功前失败次数”的几何分布。
  - 因此男孩数的期望为：
    $$
    \mathbb{E}[B]=\sum_{k=0}^{\infty} k(1-q)^k q=\frac{1-q}{q}
    $$
  - 于是每个家庭的期望构成就是：`1` 个女孩，对应 $\frac{1-q}{q}$ 个男孩，所以长期总体男女比例可写成
    $$
    \frac{1-q}{q}:1
    $$
    若把它按出生概率写成等价比例，也可理解为长期男:女仍对应 `(1-q):q`。
  - 当 `q=0.5` 时，
    $$
    \mathbb{E}[B]=1
    $$
    即平均每个家庭 `1` 个男孩、`1` 个女孩，所以长期男女比例仍然是 `1:1`。
  - 这题的核心思路是：**把“生到第一个女孩为止”看成首次成功问题，用几何分布求停止前男孩数的分布和期望。**
- **长度为 1 的棍子随机断成三段，最短段期望**：
  - 两个断点独立均匀分布在 `(0,1)` 上。设排序后断点为 `U<V`，则三段长度分别为：
    $$
    U,\quad V-U,\quad 1-V
    $$
    记最短段为
    $$
    M=\min(U,\;V-U,\;1-V)
    $$
  - 要求 $\mathbb{E}[M]$，经典做法是先求尾概率 $\mathbb{P}(M>x)$。
  - 条件 `M>x` 等价于三段都大于 `x`，也就是：
    $$
    U>x,\quad V-U>x,\quad 1-V>x
    $$
    进一步化成：
    $$
    U>x,\quad V>U+x,\quad V<1-x
    $$
  - 在单位正方形里看两个断点的位置，满足上面条件的可行区域是一个三角形；其面积为
    $$
    \mathbb{P}(M>x)=(1-3x)^2,\qquad 0\le x\le \frac13
    $$
    当 $x>\frac13$ 时，三段不可能都大于 $x$，所以概率为 `0`。
  - 因此
    $$
    \mathbb{E}[M]=\int_{0}^{\infty}\mathbb{P}(M>x)\,dx
    =\int_{0}^{1/3}(1-3x)^2\,dx
    =\frac19
    $$
  - 所以三段中最短一段的期望为：
    $$
    \mathbb{E}[M]=\frac19
    $$
  - 这题的核心套路是：**几何概率 + 尾概率积分**。很多类似“最小值/最大值期望”题都可以先求 $\mathbb{P}(M>x)$ 或 $\mathbb{P}(M\ge x)$ 再积分。
- **报数游戏（每次只能在前一个基础上加 1~10，先到 200 获胜）**：
  - 核心是“控制必胜点”。
  - 因为每轮双方报数之和可以控制为 `11`，所以应抢占形如 `2, 13, 24, ..., 200` 的位置。
  - 一般结论：目标数为 `N`、每次最多加 `k`，则关键位置是对 `k+1` 取模后的固定同余类。
- **圆环路径规划**：
  - 这类题通常考“环形结构上的最短路、动态规划、贪心或状态压缩”。
  - 由于你目前只记得题型、不记得细节，这里先记成待补全题；后续如果你想起更多约束，我再帮你恢复成完整题面与解法。

#### 1. 概率论与组合计数

- **Coupon Collector（集齐所有面/所有类型）**：
  - 集齐 `n` 类独立等概率结果的期望次数为：
    $\mathbb{E}[T] = n\left(1 + \frac12 + \cdots + \frac1n\right) = nH_n$
  - 例如 6 面骰子所有面至少出现一次的期望次数是 `6H_6 = 14.7`
- **奇偶性问题**：
  - 当单次结果“奇/偶”对称时，多个独立试验的和为奇数或偶数通常可直接用对称性求解
  - 比如单个骰子奇数概率和偶数概率都为 `1/2`，则若干个骰子点数和为奇数的概率也是 `1/2`
- **条件计数与补事件**：
  - “取最大三个值之和等于 18”这种题，先看 18 是否为最大可能值，再把条件改写成“至少 3 个骰子为 6”
  - 很多题目用补事件、拆情形、容斥原理会更快

#### 2. 随机游走、停时与赌徒破产

- **一维对称随机游走**：
  - 走 `2n` 步后回到原点，必须恰好有 `n` 次向上、`n` 次向下
  - 概率为：
    $\mathbb{P}(S_{2n}=0)=\binom{2n}{n}2^{-2n}$
- **带偏随机游走**：
  - 若每步向上概率为 `p`，向下概率为 `q=1-p`，则到达某一固定位置通常要先看“步数限制”与“是否有吸收边界”
  - 有固定步数时通常用二项分布
  - 有吸收边界时常转化为 **赌徒破产（Gambler's Ruin）**
- **赌徒破产公式**：
  - 设你当前资金为 `i`，总资金为 `N`，每轮赢 1 元概率 `p`，输 1 元概率 `q`
  - 若 `p \neq q`，先到达 `N`（获胜）而非 `0`（破产）的概率：
    $\mathbb{P}_i(\text{win})=\frac{1-(q/p)^i}{1-(q/p)^N}$
  - 若 `p=q=1/2`，则退化为 `i/N`
- **首次回到原点的期望时间**：
  - 对称随机游走从 0 出发，离开后首次回到 0 的期望时间是**无穷大**
  - 所以“不断生孩子直到男女数量相同”的期望孩子数也是无穷大（男女等概率时）
- **Martingale 策略**：
  - 经典加倍下注策略在有限资金下并不能创造正期望
  - 若底层赌局是公平的，则即便大概率小赢、极小概率大亏，总期望收益仍然通常为 0
  - 面试官常借此考你是否理解“高胜率不等于高期望”

#### 3. 锦标赛、排列与线性代数

- **随机对阵锦标赛**：
  - 若强者一定战胜弱者，则“某两支指定强队在决赛相遇”的本质是看它们是否被分到不同半区
  - 32 支队时，固定最强队位置后，第三强在另一半区的概率是 `16/31`
- **高斯随机矩阵的行列式**：
  - 若 `n×n` 矩阵元素独立同分布 `N(0,1)`，则
    $\mathbb{E}[\det(A)^2]=n!$
  - 对 `n>1`，由于行列式关于交换两行变号，所以均值为 0，方差就是 `n!`

#### 4. 机器学习理论小题

- **Ridge 遇到重复特征**：
  - 若新加一个与旧特征完全重复的特征，模型拟合效果取决于两个系数之和
  - 由于 Ridge 惩罚平方和，把同样的总系数分摊到两个变量上会降低惩罚，因此总系数往往会变大，且两个系数通常相等
  - 如果题目只说“同分布”而不是“完全相同”，则无法直接下严格结论
- **Underfitting 与少数类概率**：
  - 欠拟合模型倾向于把预测概率往总体均值拉
  - 在极度不平衡分类里，这通常意味着对少数类概率**偏低**
- **交叉熵与极不平衡类别**：
  - 从理论上讲，标准交叉熵是 proper scoring rule，理想条件下并不系统性高估或低估真实后验
  - 但在实践中，由于样本极不平衡、模型能力有限、训练目标被多数类主导，常会表现为对少数类预测概率偏低

#### 5. 常见算法母题

- **两个有序数组的中位数**：
  - 最优思路是二分查找分割点
  - 时间复杂度 `O(log(min(m,n)))`
- **删去 k 位后使数字最小**：
  - 典型解法是**单调递增栈**
  - 当前数字比栈顶小且还有删除次数时，持续弹栈
- **全排列**：
  - 经典做法是 DFS / 回溯
  - 若有重复元素，则要在同层做去重
- **整数拆分使乘积最大**：
  - 经典结论：尽量拆成多个 `3`
  - 若余数为 `1`，把一个 `3+1` 改成 `2+2`
  - 这是很多算法/数理题的高频结论
- **直到满足某条件才停止的过程题**：
  - 常见做法是：状态划分 + 递推 / 马尔可夫链 / 首步分析
  - 比如“直到出现奇数停止，问 2、4、6 是否都出现过”这类题，用状态转移比硬算更稳

#### 1. 统计与金融基础

- **年化波动率**：
  - 本质是收益率标准差的时间尺度调整
  - 日频收益率下常用：
    `年化波动率 = 日波动率 * sqrt(252)`
  - 面试里最好主动说明：如果用的是对数收益率或简单收益率，短周期下差异不大，但定义要先说清
- **大数定律 vs 中心极限定理**：
  - 大数定律关注“样本均值收敛到总体均值”
  - 中心极限定理关注“标准化后的样本均值分布趋近正态”
  - 简化记忆：前者讲“收敛到哪”，后者讲“如何分布”
- **贝叶斯定理**：
  - 公式：
    `P(A|B) = P(B|A)P(A) / P(B)`
  - 本质是“观察到证据 B 后，如何更新对事件 A 的信念”
  - 量化场景里可用于信号更新、状态判断、事件驱动概率修正
- **假设检验中的 Type I / Type II 错误**：
  - Type I：错杀真原假设，属于弃真
  - Type II：错放假原假设，属于取伪
  - 降低显著性水平会减少 Type I，但常增加 Type II
  - 金融语境下可解释为：把无效策略错判为有效，或把有效策略错判为无效
- **夏普比率的局限性**：
  - 默认用波动率衡量风险，没把下行风险单独拎出来
  - 隐含收益分布较稳定甚至接近正态的假设
  - 容易被高频、卖尾部风险、收益平滑等策略“美化”
  - 所以实务里要联合看回撤、偏度、尾部风险和容量
- **蒙特卡洛模拟估值**：
  - 核心流程：生成价格路径 -> 计算每条路径收益 -> 折现后取均值
  - 常见于期权估值、路径依赖产品定价、风险中性仿真
  - 关键参数通常包括：无风险利率 `r`、波动率 `sigma`、到期时间 `T`、模拟路径数 `N`

#### 3. 概率、统计、时序与机器学习

- **概率论建议复习方式**：
  - 用英文教材系统过一遍基本概念和课后题
  - 高频关键词可以按 `coin / dice / card / ball` 四类刷题
  - 量化面试里很多概率题本质都能归到这四类
- **数理统计高频点**：
  - 假设检验
  - 线性回归推导
  - 线性回归假设
  - `p-value`
  - `confidence interval`
  - Bias、Covariance、Correlation
  - 这些内容很多会和因子检验、策略显著性和回归解释直接相关
- **时序模型高频点**：
  - `AR`、`MA`、`ARMA`、`ARIMA`
  - `ARCH`、`GARCH`
  - 以及更高阶一点的时序建模直觉
  - 有时还会问 `PCA`，因为它在降维和共线性处理中很常见
- **机器学习概念题高频点**：
  - Logistic regression
  - Random forest
  - XGBoost
  - Neural network
  - 面试中常问的不是代码实现，而是原理、差异、适用场景和优缺点

#### 4. 线性代数与编程准备

- **线性代数高频点**：
  - `SVD`
  - 特征值分解
  - 四大空间：row space、column space、null space、left null space
  - 矩阵 rank 与这些空间的关系
  - `2x2`、`3x3` 矩阵行列式快速计算
  - Positive definite / positive semidefinite 的性质与应用
- **为什么 PSD 很重要**：
  - 组合风险很多是用 `variance-covariance` 定义的
  - 协方差矩阵天然是 positive semidefinite
  - 线性回归、二次型、风险模型这些地方都会频繁用到
- **编程准备重点**：
  - 刷 `LeetCode Top 100`
  - 优先掌握常见数据结构和算法模板
  - 对量化来说，动态规划、双指针、滑动窗口、树遍历都比较常见
  - 常见题如打家劫舍、股票最佳买卖时机、爬楼梯、滑动窗口最大值
- **排序与基础算法**：
  - 熟练掌握至少一种简单排序
  - 至少会写 `quick sort` 或 `merge sort`
  - 还常见 Fibonacci、moving average、Monte Carlo 求 `pi`
- **语言层面的面试要求**：
  - 对 Python 的函数、类、常见库和基础语法要比较熟
  - Java / C++ 不一定要求精通，但至少要能读懂基础代码
- **今年找工很难时的现实建议**：
  - 多 networking
  - 持续系统复习而不是只刷零散题
  - 把“知识点总纲 + 经典母题 + 项目问答”三条线并行准备
  - 你现在这份文档，其实就在往这个方向长
