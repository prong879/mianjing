# 考前冲刺

按「时间剩多少」选强度；每条都链接到本站具体页面，便于开浏览器直接背。

## 面前 1 小时（极简）

**数据分析 / 商分 / 数科**

- 过一遍 [SQL 知识](/knowledge/data-sql/overview) 里的「常见追问」
- 打开 [SQL 习题](/interviews/data-analytics/sql-exercises) 快速看 2～3 道窗口函数 / 留存类题思路
- 扫 [A/B 知识](/knowledge/statistics-experiment/ab-testing) 与 [A/B 习题](/interviews/data-analytics/ab-exercises) 各读「流程 + 样本量 + 护栏指标」

**AI Agent**

- [Agent 架构](/knowledge/ai-agent/agent-architecture) + [RAG](/knowledge/ai-agent/rag) 各读「常见考点 / 追问」
- [面试题合集](/interviews/ai-agent/questions) 中挑一组「模板类」小节浏览（如回答模板章节）

**量化**

- [简历面](/interviews/quant/resume-and-hr) 中的「冲刺清单 / 模板」
- [编程与数据处理](/knowledge/quant-research/programming-and-data) 里 Backtrader / vn.py 流程口述

## 考前 7 天

在 [学习路线总览](./roadmap) 的三条主线各走一轮「知识页 → 对应面试题页」，额外要求：

- **数据向**：至少完整手写或口述 5 道 SQL（留存、窗口、漏斗各覆盖）
- **Agent**：用自己的项目画一张「检索 + 工具 + 记忆」数据流
- **量化**：口述一次「因子 IC → 回测净值 → 过拟合与样本外」链条
